# Water Gun Arena

A first-person water fight. Soak the bot before it soaks you, win coins,
and spend them on bigger water guns.

Play it: https://milosarcade.com/water-gun-arena/

## Controls

| Key | Action |
|---|---|
| W A S D | Move |
| Mouse | Look |
| Click | Spray |
| R | Reload |
| Esc | Release the mouse, or pause |

Needs a keyboard and mouse.

## Bots

| Bot | Reward |
|---|---|
| Rookie Bot | 25 coins |
| Soaker Bot | 60 coins |
| Hydro Tyrant | 120 coins |

## Water guns

Squirt Pistol (free), Super Soaker (50), Pressure Cannon (150) and
Hydro Minigun (300).

## Play vs Friend

This mode connects to a separate game server that is not part of this
repo, so it does not work on the public site.

three.js is copyright its authors and used under the MIT licence.

## Files

- `index.html` is the whole game: HTML, CSS, JavaScript and three.js in one file.
